# Changelog

All notable changes to this project are documented here.

## 0.1.0 — 2026-10-26

### Added

- Flutter app scaffold for Android, iOS, and web.
- Feature-first `lib/src` structure with app, core, and feature layers.
- Riverpod `AsyncNotifier` item list with loading, error, refresh, and details.
- `go_router` configuration with a stateful bottom-navigation shell, nested
  details route, and a 404 page.
- Material 3 light and dark themes with a runtime theme switcher.
- Widget, unit, and provider tests with deterministic fakes.
- Strict analyzer configuration, lint rules, editor settings, and VS Code
  launch configurations.
- GitHub Actions CI for formatting, analysis, tests, coverage, and web builds.
- Dependabot configuration for pub and GitHub Actions updates.
